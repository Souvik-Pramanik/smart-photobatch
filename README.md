# PhotoBatch

Privacy-first bulk photo converter built with React + Vite.

## Features

- Bulk drag-and-drop upload
- Client-side image processing
- Aspect-ratio cover crop
- Exact output dimensions
- JPG / PNG / WebP
- JPEG/WebP quality control
- ZIP export
- Animated responsive UI
- No image upload to a backend

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The current crop strategy is centered. A future version can add manual crop and face-aware positioning.
